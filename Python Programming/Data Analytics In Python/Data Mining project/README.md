This was the final project of my Intro to Data Mining course. The purpose was to find the best performing algorithm binary classification algorithm that could predict income (>50k or >=50k) based on a preprepared cencus data. The project demonstrates skill and understanding regarding the CRISP-DM process, including EDA, data cleaning and tranformation, data modeling, model evaluation, and making actionable reccamendations. The code showcases imports and my reasoning for each import, both high level and indepth exploratory data analysis, encoding, and modeling. The models developed include a dummy model, decision tree, K Nearest Neighbors, Support Vector Machine, and MLP nueral network. The decision tree was the most accurate model of all other models.
