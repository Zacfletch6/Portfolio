This was the final group project of my Intro to Business Analytics course. The purpose was to predict types of movies that drive the most engagement, which is measured through popularity and revenue, using Netflix data from Kaggle. The project demonstrates skill and understanding regarding the CRISP-DM process, including business understanding, EDA, data cleaning and tranformation, data modeling, model evaluation, and making actionable reccamendations. The code showcases exploratory data analysis, data cleaning, modeling, and communication. The models developed include logical regression to predict popularity and find highest contributing features to popularity, random forest regression to predict revenue, model nonlinear relationships, and find highest contributing features to revenue, and K-Means Clustering to find traits of the best performing movies. This was a team project, and my contributions include part of the EDA and developing the K-Means Clustering model.
